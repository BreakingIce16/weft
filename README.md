# Weft

**Alpha software. No support is provided.**

Weft is a personal, work-in-progress mod editor and mod manager for *Fire Emblem: Fortune's Weave*. This page only
hosts its downloads so the author can test updates. It is not announced anywhere, it changes often, and it may break
your mods or settings without warning.

- **No support:** issues, questions and requests are not answered. If you found this by chance, you are welcome to
  look, but you are on your own.
- **No game files:** Weft contains none. It reads your own legally dumped copy of the game.
- **Unofficial:** not affiliated with or endorsed by Nintendo, Intelligent Systems or Koei Tecmo.
- **Back up** your saves and mods before using it.

## Download

Get the latest build from [Releases](../../releases/latest): Windows (zip), Linux (AppImage) or Mac (dmg).
Weft checks this page for updates on its own.
